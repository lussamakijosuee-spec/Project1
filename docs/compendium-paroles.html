Les huit éléments

Chaque élément est codé par un nombre. Ce nombre s'insère dans la parole entre le mot de passe et le nom du sort.

ÉlémentCodeDomaine

Le mot de passe · types de mana

On l'utilise comme un mot de passe : on énonce d'abord le type de mana, puis le nom du sort. La base est toujours le mana positif.

ManaCodeRôle
Positif3Le nombre universel, la base, toujours utilisé.
Négatif4Paroles offensives, de corruption ou de malédiction.
Spirituel2Paroles de l'âme, de soin, de protection.
On peut combiner les types pour des paroles hybrides — par exemple Positif + Négatif pour un sort à double nature.

Les formes de parole

V = la parole est valide, le sort part. Tout se construit à partir de trois jetons : le mot de passe, l'élément, le nom du sort.

Simple
Le cas de base.
mot + élément + sort = V
Double élément
Fusion de deux affinités. Les codes d'élément se concatènent : Feu (8) + Glace (13) → 813.
Amplifiée
Le mana multiplie la puissance du sort.
mot + (mana × sort) = V
Fusion
Deux sorts existants fusionnés en un plus puissant.
sort × sort = V
Enregistrée
Mana origine : le sort est déjà gravé, on le lance sans réciter le mot de passe ni l'élément.
sort = V
Mana origine. Le mana qui remonte de l'intérieur permet de lancer des paroles plus complexes avec moins d'énergie. Pour un lanceur accompli, certaines paroles sont enregistrées : nul besoin de dire le mot de passe ni l'élément, c'est déjà inscrit.

Les sorts de soin et de support

Pour le soin et autres effets, la parole se construit en soustraction. Le signe inverse le sens : on retire au lieu d'ajouter.

Soin · support
Le résultat enlève (dissipe un effet, draine) ou restaure (soigne, rend des forces).
mot − élément + sort = V

Combat : puissance contre lucidité

Plus une parole est longue et complexe, plus elle frappe fort, loin et juste — mais plus elle exige de concentration et de temps. C'est l'arbitrage central.

La santé mentale gouverne tout. La concentration disponible vaut talent × (santé mentale / 100). À lucidité brisée, la longueur de parole tenable s'effondre, et au-delà, c'est le backlash. Le mana origine contourne la récitation : il échappe au coût de concentration et de temps.
