La planche — 4 × 2 cases de 144 × 144, comme dans RPG Maker

    Enregistrer

    .png

    Mode d'emploi

    • Dans le générateur de RPG Maker, exporte chaque expression en visage (144 × 144).
    • Glisse les PNG sur la planche, ou clique sur une case vide. Plusieurs fichiers d'un coup se rangent par nom (1, 2, 3…) dans les cases libres.
    • Glisse une case sur une autre pour les échanger ; le × d'une case la vide. Une case vide reste transparente.
    • Une image d'une autre taille est refusée : rien n'est redimensionné.
    • « Enregistrer » écrit la planche dans img/faces. Un fichier qui existe n'est jamais remplacé : le Studio propose un autre nom. Ferme RPG Maker avant.
    • Dans RPG Maker, la case en haut à gauche est l'index 0, celle en bas à droite l'index 7.
