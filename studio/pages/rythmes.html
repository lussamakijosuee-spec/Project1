Comment ça marche
  • Les 4 couloirs sont les 4 héros de l'équipe, dans l'ordre (le 1er en haut). Les boutons sont les 8 de MOG : A, S, Z (OK), X (Annuler) et les quatre flèches. Choisis-en un dans la palette, puis clique dans un couloir : la note se pose. Clic droit dessus : elle part. Tu peux la glisser.
  • Suivre la musique : règle le tempo (tape-le avec T en écoutant), mets le 1er temps au bon endroit, et l'aimant pose les notes sur les temps. Ne pas suivre : aimant « libre », la note va exactement où tu cliques.
  • Ça accélère : clique dans la bande « vitesse » (au-dessus des couloirs) — à partir de là, les notes arrivent à cette vitesse. Clic droit sur le drapeau : il part.
  • Au clavier : lance la lecture, appuie sur ⏺, puis joue les touches A, S, Z, X et les flèches en rythme : chaque touche pose une note dans le couloir actif (1–4 pour en changer). Espace lecture/pause, Suppr efface la note choisie, Ctrl+Z annule. Molette : avancer ; Ctrl+molette : zoomer.
  • 🎮 Essayer lance le vrai jeu ici, avec la partition telle qu'elle est (même pas enregistrée). 💾 Enregistrer l'écrit dans data/rythmes/ ; RPG Maker peut rester ouvert. Dans ton événement : la commande ci-dessus. Sans partition, le Theatrhythm de MOG joue au hasard, comme avant.
